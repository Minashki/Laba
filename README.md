Сбор информации об операционной системе

Описание программы

Данная программа написана на Python и предназначена для определения операционной системы, на которой она запущена, а также для сбора основной информации о системе.

Программа работает на Windows, Linux и macOS. После запуска она собирает информацию о компьютере и сохраняет её в файл "system_info.json" в формате JSON.

В программе используются только стандартные библиотеки Python, поэтому для её запуска не требуется устанавливать дополнительные пакеты.

---

Какие модули используются

"platform"

import platform

Используется для получения информации об операционной системе и аппаратной части компьютера.

С помощью этого модуля программа получает:

- название операционной системы;
- версию и релиз ОС;
- архитектуру процессора;
- информацию о процессоре;
- версию Python;
- реализацию Python.

Главным образом этот модуль используется для определения ОС:

platform.system()

Функция возвращает название системы. Например:

- "Windows" — для Windows;
- "Linux" — для Linux;
- "Darwin" — для macOS.

Так как "Darwin" является внутренним названием платформы macOS, в программе оно заменяется на более понятное "macOS".

---

"os"

import os

Модуль предоставляет функции для работы с операционной системой.

В данной программе он используется для получения количества логических процессоров:

os.cpu_count()

Также "os" относится к стандартным средствам Python для работы с ОС и не требует установки дополнительных библиотек.

---

"sys"

import sys

Используется для получения информации о текущем интерпретаторе Python.

В программе используется:

sys.platform

Он показывает техническое обозначение платформы, на которой работает Python.

Также используется:

sys.executable

Эта команда показывает путь к исполняемому файлу Python, с помощью которого была запущена программа.

---

"socket"

import socket

Используется для работы с сетевыми функциями.

В программе он нужен для получения имени компьютера в сети:

socket.gethostname()

Это позволяет записать в JSON имя текущего компьютера.

---

"getpass"

import getpass

Используется для получения имени текущего пользователя:

getpass.getuser()

Этот способ выбран вместо ручного чтения переменных окружения, потому что "getpass" предоставляет готовую функцию для получения имени пользователя и работает на разных операционных системах.

---

"shutil"

import shutil

Используется для работы с файлами и дисками.

В программе применяется:

shutil.disk_usage(Path.cwd())

С помощью этой функции программа получает информацию о дисковом пространстве:

- общий объём;
- занятое место;
- свободное место.

Полученные значения изначально находятся в байтах. Поэтому программа переводит их в гигабайты и округляет до двух знаков после запятой с помощью "round()".

---

"json"

import json

Этот модуль нужен для создания JSON-файла.

Все собранные данные сначала хранятся в обычном Python-словаре "data", а затем функция:

json.dump(data, file, ensure_ascii=False, indent=4)

записывает этот словарь в файл "system_info.json".

Параметр "ensure_ascii=False" позволяет нормально записывать русский текст, а "indent=4" делает JSON более удобным для чтения.

---

"pathlib"

from pathlib import Path

Используется для работы с путями к файлам и папкам.

В программе:

Path.cwd()

возвращает текущую рабочую директорию программы.

Она используется сразу в нескольких местах: для определения текущей папки и для определения диска, на котором находится эта папка.

"pathlib" выбран потому, что это современный и удобный стандартный способ работы с путями в Python.

---

"datetime"

from datetime import datetime

Используется для получения текущих даты и времени.

Программа записывает время, когда была собрана информация:

datetime.now().astimezone().isoformat()

Это позволяет понять, когда именно был создан результат.

---

Как работает программа

Работу программы можно разделить на несколько этапов.

1. Определение операционной системы

Сначала вызывается функция "detect_os()".

Она получает название системы:

system = platform.system()

Если Python возвращает "Darwin", программа заменяет его на "macOS".

В результате функция возвращает понятное название операционной системы.

---

2. Сбор информации о системе

Функция "collect_system_info()" собирает:

- название ОС;
- релиз;
- версию;
- имя компьютера;
- архитектуру.

Она возвращает эти данные в виде словаря.

---

3. Сбор информации об аппаратной части

Функция "collect_hardware_info()" получает:

- название процессора;
- количество логических процессоров.

Количество логических процессоров получается с помощью:

os.cpu_count()

---

4. Сбор информации о Python

Функция "collect_python_info()" получает:

- версию Python;
- реализацию Python;
- техническое название платформы;
- путь к исполняемому файлу Python.

Например, реализацией обычно является "CPython".

---

5. Сбор информации о пользователе

Функция "collect_user_info()" получает:

- имя текущего пользователя;
- текущую рабочую директорию.

---

6. Получение информации о диске

Функция "collect_storage_info()" получает информацию о диске, на котором находится текущая рабочая папка.

Размеры переводятся из байтов в гигабайты:

disk.total / (1024 ** 3)

После этого результат округляется:

round(..., 2)

Поэтому в JSON значения выглядят, например, так:

"storage": {
    "total_gb": 931.51,
    "used_gb": 450.23,
    "free_gb": 481.28
}

---

7. Объединение всех данных

После выполнения всех функций создаётся словарь "data".

Он содержит несколько разделов:

metadata
system
hardware
python
user
storage

Использование словаря позволяет хранить данные в структурированном виде и удобно преобразовать их в JSON.

---

8. Запись результата в JSON

После сбора всей информации программа открывает файл:

with open("system_info.json", "w", encoding="utf-8") as file:

""w"" означает, что файл открывается для записи.

Если файла ещё нет, он будет создан. Если файл уже существует, его содержимое будет заменено новым результатом.

Затем:

json.dump(data, file, ensure_ascii=False, indent=4)

записывает собранную информацию в этот файл.

---

Структура результата

Примерная структура созданного JSON-файла:

{
    "metadata": {
        "collected_at": "2026-10-01T17:30:00+03:00"
    },
    "system": {
        "os": {
            "name": "Windows",
            "release": "11",
            "version": "..."
        },
        "hostname": "Computer",
        "architecture": "AMD64"
    },
    "hardware": {
        "processor": "...",
        "logical_cpu_count": 12
    },
    "python": {
        "version": "3.13.0",
        "implementation": "CPython",
        "platform": "win32",
        "executable": "..."
    },
    "user": {
        "username": "...",
        "working_directory": "..."
    },
    "storage": {
        "total_gb": 931.51,
        "used_gb": 450.23,
        "free_gb": 481.28
    }
}

Почему используются функции

Для каждой группы информации создана отдельная функция. Например:

collect_system_info()
collect_hardware_info()
collect_python_info()

Это позволяет не складывать весь код в один большой блок. Каждая функция отвечает за свою задачу, поэтому программу проще читать, проверять и при необходимости изменять.

При этом функции возвращают обычные словари Python, которые потом объединяются в одну структуру "data".

---

Запуск программы

Для запуска необходимо выполнить:

python my_script.py

После выполнения в папке запуска появится файл:

system_info.json

В него будет записана собранная информация о текущей системе.

Итог

В результате программа автоматически определяет операционную систему и собирает набор основных параметров компьютера, Python и пользователя. Все данные сохраняются в структурированном JSON-файле.

Для реализации используются только стандартные модули Python. Это позволяет запускать программу на Windows, Linux и macOS без установки сторонних библиотек.
